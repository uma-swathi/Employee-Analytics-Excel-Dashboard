# 📊 Employee Analytics Excel Dashboard

## Project Overview

This project is an **Employee Analytics Dashboard built using Microsoft Excel**. It provides an interactive view of employee information, salary, departments, experience, and performance.

The dashboard was created to practice **Excel data analysis, Pivot Tables, lookup functions, formulas, and data visualization**.

## 📁 Dataset

The employee dataset contains:

* Employee ID
* Employee Name
* Department
* Job Role
* City
* Experience
* Salary
* Joining Date
* Performance Rating

## 📈 Dashboard Analysis

The dashboard provides insights into:

* Total Employees
* Employee distribution by Department
* Average Salary by Department
* Employee Experience
* Salary Analysis
* Performance Rating
* Job Role Analysis
* City-wise Employee Distribution


## 📊 Dashboard Features

The dashboard uses charts and summarized data to make employee information easier to understand and analyze.

Pivot Tables were used to summarize employee data, while lookup functions were used to retrieve specific employee information.

## 🎯 Project Objective

The objective of this project is to demonstrate practical **Excel Data Analytics and Dashboard Development skills** that can be applied to real-world HR and employee datasets.

## 🧰 Tools Used

**Microsoft Excel**
